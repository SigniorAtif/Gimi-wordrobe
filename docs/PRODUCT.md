# Product: Skin Switcher

register: product

## Users
One player (the repo owner) who runs Genshin Impact with GIMI/XXMI (3DMigoto) mods on Windows. They alt-tab out of a
full-screen game in the evening, pick which outfit each character wears, hit Apply, then press F10 back in game.
They are comfortable with mods but do not want to think about folders, `DISABLED` prefixes or `d3dx_user.ini`.

## Product purpose
Turn "enable one mod folder per character" into "choose an outfit". Only one skin per character may be active.
The app owns the disk work (batched moves with rollback) so the user never breaks their Mods folder.

## Tone
Calm, confident, a little playful in motion, never loud. Feels like a wardrobe, not a file manager.
Copy is short and concrete ("Applied. Press F10 in game to reload.").

## Strategic principles
- Skin covers are the hero. Chrome stays quiet and dark so artwork carries the colour.
- Nothing snaps: every navigation and state change animates (SPEC §7), fast and physical, never slow.
- Safety is visible: pending changes are always summarised in the bottom bar before anything touches disk.
- NSFW content is hidden by default and leaks nowhere (names, covers, counts, search).

## Anti-references
- Generic mod managers with dense tables, tiny checkboxes and grey Win32 chrome.
- Neon "gamer" UI, RGB glows, official game logos or branding.
- Glassmorphism everywhere, gradient text, purple-to-blue hero gradients.

## Scene
Evening, a dim room, a 27" monitor; the game is paused behind the window in full-screen dark scenes.
Dark UI is forced by that scene and by SPEC §1 (dark mode only).
